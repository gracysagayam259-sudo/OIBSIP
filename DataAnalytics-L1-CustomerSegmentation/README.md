# Customer Segmentation Analysis

## OIBSIP Data Analytics - Level 1 - Task 2

### Project Overview

This project performs customer segmentation using RFM analysis and the K-Means clustering algorithm.

The objective is to identify distinct customer groups based on purchasing behaviour and provide targeted marketing recommendations.

### Dataset

The project uses the Online Retail dataset containing customer transaction information.

### Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

### Methodology

- Data inspection
- Data cleaning
- RFM analysis
- Feature standardization using StandardScaler
- Elbow Method
- K-Means clustering
- Cluster profiling
- Customer segment visualization
- Marketing recommendations

### Customer Segments

- Champions
- Loyal Customers
- Regular Customers
- At-Risk Customers

### Key Insights

The analysis identifies high-value customers, loyal customers, regular customers, and customers who may require re-engagement.

The segmentation can help businesses develop targeted marketing and customer retention strategies.

### Conclusion

RFM analysis combined with K-Means clustering provides meaningful customer segments that can support data-driven marketing decisions.

# EDA on Retail Sales Data

## OIBSIP Data Analytics - Level 1 - Task 1

### Project Overview

This project performs Exploratory Data Analysis (EDA) on a retail sales dataset to identify sales patterns, customer behaviour, and product-category performance.

### Objectives

- Inspect the dataset and check data quality
- Perform descriptive statistical analysis
- Analyse monthly and quarterly sales trends
- Analyse customer demographics
- Analyse product-category performance
- Study correlations between numerical variables
- Identify useful business insights and recommendations

### Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

### Key Analysis

- Monthly and quarterly sales trends
- Age group analysis
- Gender analysis
- Product category analysis
- Quantity analysis
- Correlation analysis
- Customer spending behaviour

### Key Findings

- May 2023 recorded the highest monthly sales.
- Clothing had the highest quantity sold among the product categories.
- Price per Unit showed a strong positive relationship with Total Amount.
- Customer spending behaviour varied across age groups and genders.
- Sales performance varied across different months and quarters.

### Conclusion

The analysis provides useful insights into customer spending patterns, sales trends, and product-category performance that can support data-driven business decisions.
